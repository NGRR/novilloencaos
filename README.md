# novilloencaos

Archivo personal de ensayos, apuntes y comentarios sobre filosofía, tecnología, cultura e inteligencia.

## Estructura

```text
novilloencaos/
├── index.html
├── .nojekyll
├── assets/
│   ├── css/
│   │   └── site.css
│   └── js/
│       └── site.js
└── ensayos/
    └── despues-del-vacio/
        └── index.html
```

## Sistema editorial

El sitio funciona como un archivo HTML estático. La portada organiza las entradas de forma cronológica y cada ensayo vive en una ruta independiente. El sistema visual utiliza una retícula técnica, cotas, numeración, notas marginales y una paleta predominantemente blanca para mantener el foco en la lectura larga.

### Publicado

- **001 — Después del Vacío**: ensayo sobre la autotranscendencia humano–máquina, la transferencia de método, la obsolescencia de la IA y la posibilidad de pensar después de su disolución funcional.

## Publicación

Preparado para GitHub Pages desde la rama `main` y la raíz `/`.
